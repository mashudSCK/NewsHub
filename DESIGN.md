# NewsHub editorial system

Approved direction: editorial newsroom. Mode: Read.
Paper #F7F5F0, ink #172521, forest accent #1E6049, fine rules, restrained surfaces.
Newsreader headlines and masthead; Inter interface and body. Fonts are bundled locally.
1200px content width plus 32px desktop / 20px mobile gutters; lead story with three supporting headlines, then two-column compact rows.
Mobile follows reading order with one column. Dark mode uses forest-toned surfaces and pale text.
Avoid emoji headings, decorative gradients, unrelated image fallbacks, and repetitive identical cards.
See docs/newshub-design.md for the full approved proposal and docs/evidence for rendered output.
